Knowledge Tracks

15 个方向覆盖一个生产级 Agent 的主要工程面。

01Models

模型能力、成本、延迟、工具调用和结构化输出。

 02Instruction

任务设计、提示词、JSON Schema 和约束生成。

 03Runtime

Agent loop、状态、会话、流式、暂停和恢复。

 04Skills

能力封装、触发、检索、组合与评测。

 05Tools

工具 schema、参数校验、权限、错误和结果设计。

 06MCP

Tools、Resources、Prompts 和外部能力协议化。

 07RAG

文档解析、切分、Embedding、检索、引用和 freshness。

 08Memory

用户记忆、项目记忆、压缩、污染和长期上下文。

 09Workflow

顺序、图、Router、Supervisor、Handoff 和并行 Agent。

 10Agent UI

工具调用展示、运行时间线、人工审批和反馈。

 11Evaluation

任务成功率、工具正确率、RAG Eval 和回归测试。

 12Trace

Run log、Replay、token cost、latency 和失败分析。

 13Security

Prompt injection、数据权限、工具权限和红队测试。

 14Sandbox

浏览器、Shell、代码执行、文件边界和 Playwright Agent。

 15Adapters

LiteLLM、OpenRouter、Vercel AI SDK 和 Runtime 兼容性。

Experiment Flow

每个判断都尽量落到实验、对比和复盘里。

首页保持通用定位，真实业务系统可以放进 experiments 或 case-studies。 这样仓库既能展示完整知识体系，也能逐步沉淀可验证的工程证据。

  1. Question先写清楚要验证的问题，例如模型工具调用是否稳定。
  2. Setup固定模型、Runtime、工具 schema、数据集和评测指标。
  3. Run记录输入、输出、tool call、trace、latency、cost 和失败样例。
  4. Review把结论回写到 best-practices、comparisons 或 docs 章节。
