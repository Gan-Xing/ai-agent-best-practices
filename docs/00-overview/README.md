# Overview

This section defines the repository direction, knowledge map, terminology, and learning roadmap.

## Core idea

AI Agent engineering should be studied by implementation layers, not by vendor names only.

```txt
Model Providers
  ↓
Model Gateway / Adapter
  ↓
Agent Runtime
  ↓
Skills / Tools / MCP
  ↓
RAG / Memory / Context
  ↓
Workflow / Multi-Agent
  ↓
Evaluation / Observability / Guardrails
  ↓
Sandbox / Browser / Production UI
```
