# Terminology

## Agent

A system that can use models, instructions, tools, memory, context and workflows to complete tasks with some autonomy.

## Runtime

The execution engine that manages the agent loop, state, tool calls, retries, streaming, pause/resume and final answer.

## Tool

A single callable capability, often defined by name, description, input schema and an execution function.

## Skill

A reusable capability package that may include instructions, scripts, tools, resources, workflows and verification steps.

## MCP

Model Context Protocol. A protocol for exposing tools, resources and prompts to AI applications.

## Context Engineering

The practice of selecting, organizing, compressing and injecting the right context into the model at the right time.
