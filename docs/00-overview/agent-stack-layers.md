# Agent Stack Layers

## Layer 1: Model Providers

OpenAI, Anthropic, Google, DeepSeek, Qwen, Kimi, GLM, local open-source models.

## Layer 2: Model Gateway / Adapter

LiteLLM, OpenRouter, Vercel AI SDK, provider adapters.

## Layer 3: Agent Runtime

OpenAI Agents SDK, LangGraph, Google ADK, Pydantic AI, smolagents, custom lightweight runtime.

## Layer 4: Capability Layer

Skills, tools, MCP servers, workflows, domain procedures.

## Layer 5: Knowledge Layer

RAG, memory, context engineering, graph memory, project/user memory.

## Layer 6: Reliability Layer

Evaluation, tracing, replay, guardrails, sandboxing, human approval.

## Layer 7: Product Layer

Agent UI, generative UI, timeline UI, approval UI, feedback UI, dashboards.
